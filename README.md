## 🌟 จุดเด่นของโปรแกรม (Features)

1. **รองรับ 2 แพลตฟอร์ม (Android & Apple iOS):** ตรวจจับเครื่องและสลับโหมดอัตโนมัติ
2. **สแกนไวรัสและมัลแวร์ครบวงจร:** ดักจับแอปดูดเงิน, สปายแวร์, โทรจัน, สิทธิ์แอบอ่าน SMS OTP, และแอปแฝงตัวไร้ไอคอน
3. **ศูนย์เกราะป้องกันถาวร (Anti-Reinfection Shield):** เปิด DNS ป้องกันโฆษณาและเว็บอันตรายทั่วระบบ + ล็อกห้ามแอบโหลด APK เถื่อน ไม่ให้กลับมาติดซ้ำ
4. **🎯 จับโฆษณาหน้าจอ (Live Popup Catcher):** จับผู้ร้ายที่กำลังเด้งโฆษณาคาหน้าจอมือถือได้ทันที
5. **🌐 ล้างสแปมเบราว์เซอร์:** ตัดวงจรสแปมแจ้งเตือนไวรัสปลอมและเว็บพนันจาก Chrome
6. **📂 กวาดล้างไฟล์ .APK ตกค้าง:** ค้นหาและลบไฟล์ติดตั้งในโฟลเดอร์ Download ป้องกันการเผลอกดติดตั้งซ้ำ
7. **🔓 ปลดล็อก Device Admin อัตโนมัติ:** จัดการมัลแวร์ที่ฝังสิทธิ์แอดมินล็อกการลบ
8. **📄 ใบรายงานสรุปผล:** ออกรายงานผลการตรวจเช็กและล้างเครื่องในรูปแบบ HTML สวยงาม
9. **🔄 อัปเดตอัตโนมัติผ่าน GitHub:** ตรวจหาและติดตั้งเวอร์ชันใหม่จากเมนูในโปรแกรมได้ทันที

## 🚀 วิธีการใช้งาน

1. แตกไฟล์ `.zip` ที่ดาวน์โหลดมา
2. ดับเบิลคลิกเปิดไฟล์ `DroidAdBuster.exe`
3. เชื่อมต่อโทรศัพท์มือถือเข้ากับคอมพิวเตอร์ผ่านสาย USB:
   - **Android:** เปิด *การแก้ไขข้อบกพร่อง USB (USB Debugging)* ในตัวเลือกนักพัฒนา
   - **iOS:** เสียบสายแล้วกด *'เชื่อถือคอมพิวเตอร์เครื่องนี้' (Trust This Computer)* บนหน้าจอ iPhone
4. คลิกปุ่ม **"🚀 เริ่มสแกนความปลอดภัย"** หรือ **"🛡️ ป้องกันถาวร (1-Click)"**
